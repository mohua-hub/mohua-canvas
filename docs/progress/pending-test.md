# 待测试

## 桌面端名称

- 启动页、桌面窗口标题和启动错误弹窗统一显示“墨华画布”。

## RunningHub 与 ComfyUI 工作流渠道

- 新增 RunningHub 工作流和 ComfyUI Bridge 渠道，后台与本地配置支持工作流发现、字段映射和任务执行；需确认桌面包中的 Bridge 下载文件能在目标设备连接本机 ComfyUI，并完成检查、生成、轮询、断连恢复和媒体预览。
- 确认 RunningHub Base URL、API Key、工作流检查与字段覆盖，在图片、视频和音频入口执行并轮询结果；桌面内置后端重启后核实未完成任务恢复。配置远程 `API_BASE_URL` 时，确认 Bridge 启动命令使用可从 Bridge 设备访问的后端地址。

## 桌面自动更新

- 首次手动安装带 updater 的 Windows NSIS 版本后，确认仅 NSIS 安装可检查和安装应用内更新；Windows MSI 继续手动更新。v0.1.4 及更早版本需要先手动升级一次。
- 发布新版本后确认 Release 的 `latest.json` 只包含 Windows NSIS 目标，签名验证、下载进度、安装和应用重启正常；无更新、网络错误和签名无效时显示可恢复提示。
- 更新器签名密钥轮换或缺少 `TAURI_SIGNING_PRIVATE_KEY` 时确认构建失败并显示明确原因；私钥不进入安装包、日志、源码或 Release 附件。

## 桌面端内置后端

- 未运行外部 Go 服务、未设置 `API_BASE_URL` 时安装并启动桌面包，确认 `/api/settings` 和 `/api/prompts` 可访问；8080 被其他程序占用时仍应使用独立的内置后端。
- 首次启动应创建独立 SQLite 数据库；后台同步提示词、配置渠道后确认前台展示，重启和升级后数据仍在。新数据库不自带开发环境中的提示词和渠道。
- 默认自动生成的登录密钥持久化，确认重启后未过期登录和匿名上传身份仍有效；显式 `JWT_SECRET` 保持优先。
- 指定外部 `API_BASE_URL` 时确认只启动 Next、连接指定服务并使用该服务数据；退出桌面程序不停止外部服务。
- 确认 Go 就绪后才启动 Next，启动超时、Go 或 Next 中途退出时显示错误及日志位置；正常关闭或强制结束桌面主进程后不残留 Go / Node 进程，日志输出互不覆盖。
- 确认 Windows x64 安装包包含 Go 后端，无需额外安装 Go；开发模式仍手动启动后端。

## 桌面端启动与仓库链接

- 开发模式未启动 Go 后端或指定的外部后端不可用时，首页提示词展示改为区域内不可用提示，不再弹出全局接口错误；后台公共配置加载失败被处理，现有本地配置保留。需确认本地画布与素材仍可使用。
- 连接可用后端后，首页提示词正常展示；登录、生成等主动操作的失败提示不被屏蔽。提示词查询复用全局 React Query 的缓存与重试配置。
- 顶部 GitHub 入口、自动版本检查、更新弹窗的 VERSION / CHANGELOG.md 来源统一指向 mohua-hub/mohua-canvas。需确认不再读取上游最新版本。

## 桌面端发布

- Tauri 2 内置 Node 22、Go 后端、Next standalone、public 和静态资源；需在未安装 Node / Go 的电脑上确认安装、启动和动态画布路由。
- 首次启动解压到可写缓存目录；需确认二次启动、升级后启动、目录包含中文或空格时的表现。
- 固定本地端口与单实例；需确认重启后未登录项目、素材、模型配置仍在，重复打开聚焦原窗口。
- 正常退出和意外结束时清理 Node 和内置 Go 服务；需确认关闭后端口释放、前端端口占用时有明确错误、运行日志可定位。
- Windows 关闭 Tauri 原生拖放接管，保留画布 HTML5 拖放；需确认图片拖入、素材拖放、导出、下载和剪贴板。
- 复用项目标识生成 PNG、ICO、ICNS 图标；需确认 Windows 任务栏、安装器和应用图标。
- VERSION 同步前端、Cargo 与 Tauri；GitHub Actions 按标签只构建 Windows x64 的 NSIS 与 MSI，成功后上传 Release。macOS/Linux 安装包构建已关闭，本机 `tauri:build` 在非 Windows 系统应显示明确错误。
- 桌面包内置 Go 后端；需验证内置后端和外部 `API_BASE_URL` 两种模式下的登录、云端同步、代理、OAuth 跳转等在线功能。前端直链接口仍依赖上游允许 CORS。
- 当前 Windows 未配置开发者证书；安装确认流程需实机验证。
