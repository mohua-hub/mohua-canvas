# RunningHub 画布独立接口待测试

本次变更尚未执行语法检查、构建或测试，以下事项需要使用真实 RunningHub 配置确认。

- 在设置中配置并启用 RunningHub AI 应用、工作流；从画布工具栏的 RunningHub 集合搜索、筛选和选择，确认普通模型选择器不再把 RunningHub 条目列为模型，普通画布节点不继承 RunningHub 默认选择。
- 工具栏应显示 RunningHub 文字入口；仅配置 RunningHub 时，图片、视频、音频及生成配置节点的模型菜单应正常展开，并可选择“RunningHub 集合”插入参数节点，不再直接弹出配置窗口或显示未配置的默认模型。
- 集合默认显示“全部集合”，个人与可用系统条目同时出现并标注归属；未启用系统条目时全部集合仍正常显示个人条目。
- 工作区仅保存了素材或存储配置、尚无本地模型配置时，打开全部集合应正常显示可用系统条目，不应报本地配置格式错误。
- 工作区尚无工作流配置时，后端加载完成后添加本地 RunningHub 应用，点击渠道窗口“完成”及配置窗口“完成”；重新打开集合及刷新页面，确认条目和字段均可读取。
- 插入后确认节点名称、应用或工作流类型、启用字段、中文标签、默认值、数值范围、枚举、必填标记及随机值设置与渠道配置一致；应用 `fieldData` 中的默认说明项不应成为枚举选项。
- 连接多张参考图、参考视频、音频和蒙版对应的图片节点，逐字段选择素材后运行；确认各字段与素材序号一致，未使用的连接素材不应被额外提交，缺少必填素材时显示具体提示。
- 编辑提示词字段，或切换为使用上游文本；确认请求使用节点参数，不被全局模型的尺寸、质量、摄像机或语音配置覆盖。
- RunningHub 渠道仅显示一个 API Key 输入框；确认参数拉取、素材上传、任务提交和查询均使用设置中保存的 Key，修改后各接口同步使用新 Key。保存时留空仍沿用已保存密钥。
- 确认素材上传使用 V2 binary 接口，以渠道 API Key 进行 Bearer 鉴权，multipart 仅提交 `file`，上传返回的 `fileName` 写入目标字段。
- 运行 AI 应用与工作流，确认提交接口分别使用 `webappId` 和 `workflowId`，生成结果连接到参数节点，图片比例和多图结果沿用现有展示方式。
- 确认 V2 query 的排队、运行、成功、失败处理；失败原因显示于结果节点，重试保留字段参数和素材选择。生成期间刷新页面或重启后端，确认已提交任务继续查询并回填结果。
- 在渠道配置修改字段后刷新节点参数，确认保留仍存在的输入并添加新字段默认值；更换集合条目时重置参数。确认浅色、深色主题和较多字段时的滚动与输入正常。
- 确认本地与系统集合均可直接使用，系统集合遵循公开名单；非 RunningHub 条目不能通过独立运行入口提交，任务保存在共享工作区。
- 后端不可用时画布参数和项目仍可本地保存，RunningHub 集合读取与运行提示连接后端；后端连接且同步可用时，参数节点和字段值随项目同步。
